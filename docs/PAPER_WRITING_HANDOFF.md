# Two-session setup: experiments vs. paper writing

From 2026-11-07 the work is split between two Claude Code sessions in the same repository.

| | Experiment session (the original one) | Paper-writing session (new) |
|---|---|---|
| Owns (only it edits) | `outputs/`, `scripts/`, model code, `docs/EXPERIMENT_LOG.md`, `docs/PAPER_RESULTS.md` (generated), `docs/RESULTS_FOR_PAPER.md`, `docs/METHOD.md`, tmux `motion` jobs, GPUs | `paper/` (all `.tex`, `main.bib`, `paper/figures/`), `docs/PAPER_WRITING_NOTES.md` |
| Reads | `docs/PAPER_WRITING_NOTES.md` (requests from the writer) | everything else, read-only |
| Never | edits `paper/` | runs GPU jobs, edits scripts / outputs / experiment docs, invents or rounds numbers differently |

One owner per file means the two sessions never overwrite each other, and the Overleaf sync sees a single local
author for `paper/`.

## How results reach the paper
1. The experiment session appends a dated entry to `docs/RESULTS_FOR_PAPER.md` whenever a result is ready for the
   paper (or changes one already there): the claim in one sentence, the exact numbers, which table / section / red
   block it affects, and whether it is **final** or **preliminary**.
2. Full tables with sources: `docs/PAPER_RESULTS.md`, regenerated by `python scripts/collect_results.py`
   (experiment session). Every number there names its raw log.
3. The writer moves entries into the `.tex`, turns `\red{...}` into normal text only for entries marked final, and
   records what it incorporated (entry date) in `docs/PAPER_WRITING_NOTES.md`.
4. The writer asks for analyses, figures or checks under "Requests for experiments" in
   `docs/PAPER_WRITING_NOTES.md`; the experiment session reads that file at each check and answers in the feed.

## Paper conventions (both sessions)
- `\red{...}`: text or numbers that will change (experiments running). `\TODO{...}`: missing part. Before submission
  the two lines in `paper/preamble.tex` switch them off.
- No em dashes in the paper. Plain, short sentences; terms explained on first use.
- Numbers only from `docs/RESULTS_FOR_PAPER.md` / `docs/PAPER_RESULTS.md`; never from memory or by estimation.
- Embody-3D paper numbers pool the fresh evaluation groups 1-4; group 0 (used to choose recipes) only for ablations.
- Citations: add to `paper/main.bib`; uncertain entries get a `% VERIFY` comment line ABOVE the entry (BibTeX does not
  allow comments inside an entry).
- Overleaf sync (writer): `python3 scripts/overleaf_sync.py --config ~/.config/overleaf_sync_speechmotion.json`
  before and after editing; a loop also runs every 2 min in tmux `motion:overleaf`. On a conflict: stop and ask.
  Never read the token file; never force-push. Guide: `docs/OVERLEAF_SYNC.md`.
- Local compile check (missing local packages are stubbed in a scratch dir, Overleaf has them): `cd paper &&
  latexmk -pdf -outdir=/tmp/build main.tex`. Overleaf is the reference compile.
- Deadlines: paper Nov 16 AoE (about Nov 17 18:00 BDT), supplementary Nov 23.
